# My Portfolio Website - Module 3 🚀

Welcome to my personal portfolio repository! This project marks the successful completion of **Module 3** of my web development learning journey.

---

## 🌟 Project Overview & Features
* **Responsive Layout:** Structured cleanly with distinct Home, About Me, Skills, and Contact sections.
* **Interactive Dark/Light Mode:** 
  * Features a dynamic theme toggle button (`🌙`/`☀️`) placed in the navigation bar.
  * Uses JavaScript to seamlessly toggle between light and dark themes.
  * Implements `localStorage` to remember and persist the user's preferred theme across page reloads.
  * Utilizes smooth CSS transitions and dynamic background image overlays (`linear-gradient`) for an optimized visual look.
